# TKRV Skills

Собственные навыки для ChatGPT Work, Codex App и Codex CLI. Исходники каждого навыка лежат в `skills/<имя>/`, версии и изменения — в [релизах GitHub](../../releases).

| Навык | Когда использовать |
| --- | --- |
| [Внедрить скиллы](skills/adopt-skills/SKILL.md) | Оценить внешние навыки, выбрать полезные, адаптировать и установить их в нужных средах, затем обновить инженерный каталог |

Для уже установленного навыка выбери **«Внедрить скиллы»** через `@` в ChatGPT Work или введи `$adopt-skills <ссылка или архив>` в Codex. Добавь `dry-run` для оценки без установки.

## Как организовать внедрение навыков

Если навыки используются в нескольких проектах или средах, заведите в своём инженерном репозитории короткий каталог. Для каждого навыка укажите, какую задачу он решает и когда его выбирать, откуда взят исходник, какую версию вы проверили и где он установлен. Чтобы запись оставалась актуальной, обновляйте её в той же задаче, в которой добавляете или меняете навык.

Храните один редактируемый исходник. Установленные копии и архивы привязывайте к версии, а доступность проверяйте отдельно в каждой среде. Для первой оценки удобно запустить навык с `dry-run`.
